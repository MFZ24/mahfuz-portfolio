MAKSUDUL HASAN MAHFUZ — PORTFOLIO WEBSITE
1. Extract the entire ZIP into one folder.
2. Open index.html in Chrome, Edge or Firefox.
3. To edit: right-click index.html, style.css, projects.js or script.js and open with Notepad++ (UTF-8 encoding).
4. Keep the images folder in the same directory as index.html.
5. Internet access is required for Bootstrap CSS and the responsive Bootstrap menu (CDN). All project photos are local.
6. To change project content, edit projects.js. To change the profile, research or education, edit index.html.
7. The contact link opens the default email application; no backend or contact form is included.
8. The site includes 17 photographs extracted from Project Name.docx and the CV portrait. No invented photographs for the two hospital projects. Personal street address, phone, family details, birth date and references are intentionally omitted for public web privacy. Confirm permission to publish project images and the email address before hosting.

9. The hero slideshow uses four original field photographs and changes every five seconds. Edit the heroCarousel markup in index.html to change the photos. All six projects appear together under Project. Education displays only the bachelor degree.
